**Robots World**

![Robots World](images/robots_world.png)

**Project:**
- **Description:** A small robots-world simulation implemented in the repository. The simulation is driven by the main script at [final_project.py](final_project.py).

**Preview:**
- Image above shows the robots' environment and a sample scene from the simulation.

**Requirements:**
- **Python:** 3.8+

**Run:**
- **Run Command:** `python final_project.py`

**Files:**
- **Main Script:** [final_project.py](final_project.py)
- **Screenshot / World Image:** images/robots_world.png (place your image here)

**How to include the image:**
- Create an `images` folder next to this README and place the robots world image named `robots_world.png` at `images/robots_world.png`. The README already references that path so the image will display on GitHub or any Markdown viewer.

**Notes:**
- If your image uses a different filename, update the Markdown image link at the top of this file to match.
